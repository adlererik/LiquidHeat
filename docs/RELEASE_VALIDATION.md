# Release validation — v1.0.0

This page records package verification, not a claim of scientific accuracy. Tests run on a Linux amd64 Debian server using a separate Compose project and fresh persistent volume. The production stack and unrelated workloads are outside that project. Application containers are not run on the development workstation.

Package-specific checks and results will be recorded here after execution. The initial learning model has not accumulated enough prospective outcomes to claim a validated champion. Screenshot data is real public market output. A clean source-only Git history excludes private operational records and account secrets.
