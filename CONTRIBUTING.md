# Contributing

Please open a focused GitHub issue or pull request describing the observable problem and how to reproduce it. Include versions and redacted errors. Never include server addresses, credentials, .env files, account data or database dumps.

Use only free/open-source runtime dependencies and genuinely free public market data. Keep observed reports separate from estimates, preserve native contract units and as-of provenance, and do not add fabricated market history to the live application. Synthetic fixtures belong only in isolated tests. Changes to scientific claims need prospective evidence, not a nicer chart.

Run unit/numerical checks, relevant actual-data integration tests and installer checks. See docs/DEVELOPMENT.md. Contributions are under Apache-2.0.
